# DPDR — Definitive Polyhedral Dice Roller

DPDR is a Windows desktop application for rolling polyhedral dice for tabletop role-playing games.

## Download

Download the latest Windows executable from the **Releases** section.

DPDR is distributed as a self-contained Windows x64 executable. No separate .NET installation is required.

## System Requirements

- Windows 10 or later
- x64 processor
